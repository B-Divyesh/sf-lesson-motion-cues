# Demo sandbox

- URL: <https://lesson-motion-cues.sociobot.in/demo>
- Entry: select **Try it with sample data** on the first screen.
- Sample: “How pollination travels,” a 20-second lesson with Bee, Flower, Pollen, and seven enter, move, say, and highlight cues.
- Label: the sticky banner says **Demo — sample data, nothing is saved.**
- Reset: **Reset demo** restores the shipped pollination lesson.
- Exit: **Start for real** returns to the real editor.
- Isolation: demo state stays in memory. It never reads or writes the real `lmc:project:v1` localStorage key. Reloading `/demo` reseeds the sample.

Every browser claim uses `/demo` or creates a fresh real project without an account.
